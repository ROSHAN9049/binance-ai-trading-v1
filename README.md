# Binance AI Trading V1

Separate paper-trading project. This repository is independent from PrimeChoice.

## Stage A — Paper Trading

- Virtual capital: ₹2,000
- Markets: BTC/USDT and ETH/USDT
- Risk: 1% virtual capital per trade
- Maximum trades/day: 3
- Stop after 3 consecutive losses
- Spot-style paper trading only; no futures or leverage
- Simulated fees and slippage
- Target: 100 completed paper trades

## Planned metrics

- Net P&L
- Win rate
- Profit factor
- Maximum drawdown
- Average risk/reward

## Safety

Stage A uses no Binance account credentials and places no real orders. Live trading is explicitly out of scope until Stage A is completed and reviewed.
